# AI Study Assistant

AI Study Assistant is a Flask-based web application that helps students organize and manage their study notes efficiently.

## Features

* User Registration & Login
* Secure Authentication
* PDF Notes Upload
* Automatic PDF Summary Generation
* Search Notes
* Quiz Generator
* Category-wise Note Management
* Analytics Dashboard
* Dark Mode
* User Profile Management
* Change Password Feature

## Tech Stack

* Python
* Flask
* SQLite
* HTML
* CSS
* Bootstrap 5
* JavaScript

## Installation

1. Clone the repository

```bash
git clone https://github.com/ShravaniChitale/AI-Study-Assistant.git
```

2. Navigate to project folder

```bash
cd AI-Study-Assistant
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```
